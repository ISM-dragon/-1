هذا المجلد يحتوي على تطبيق ISM للموبايل، وهو عميل Android أصلي مبني باستخدام Kotlin وJetpack Compose وRoom وWorkManager وMedia3.

## تجربة الاستخدام

واجهة التطبيق موجهة للاستخدام الشخصي السريع: الشاشة الرئيسية تبدأ بمصدر فيديو أو ملف محلي، والاستوديو يعرض نتائج القص، والمكتبة تحفظ المشاريع، بينما يجمع «مركز التحكم» التحليلات والمقارنة وإدارة مزودي الذكاء الاصطناعي دون ازدحام شريط التنقل.

## محرك المعالجة

يستخدم التطبيق طبقة `ProcessingEngine` لاختيار مسار التنفيذ قبل جدولة العمل. في APK الشخصي، يجب ضبط عنوان Gateway الخاص ورمز الجلسة؛ عندها تُرسل الملفات المحلية إلى `ProcessingGatewayClient`، ويشغّل Gateway الـPython pipeline خارج الهاتف. لم يعد `VideoProcessingWorker` يشغّل `ProductionVideoPipeline` المحلية كـfallback، مع إبقاء ذلك المنسق في شجرة المصدر للعزل أو العمل الأصلي المستقبلي. يحفظ العامل الحالة والتقدم في Room، ويدعم الإلغاء وإعادة المحاولة والاستئناف عند توفر checkpoint بعيد.

لا توجد نتائج وهمية أو نسب تقدم مصطنعة: الواجهة تعرض الحالة التي يرسلها Gateway الفعلي، وتُرفض مصادر الفيديو أو إعدادات Gateway غير الصالحة قبل إنشاء مهمة WorkManager.

## البناء المحلي

من داخل هذا المجلد:

```bash
./gradlew :app:testDebugUnitTest
./gradlew :app:lint
./gradlew :app:assembleDebug
```

## العلاقة مع المستودع

المشروع الأصلي في جذر المستودع هو تطبيق سطح المكتب وطبقة Gateway وPython Pipeline. لا تُنسخ ملفات `app/src` إلى جذر مشروع Tauri؛ يبقى تطبيق Android هنا كعميل مستقل يستخدم عقد Gateway المشترك عند تفعيله.

## الخصوصية

تبقى قاعدة Room وإعدادات Gateway المشفرة داخل التطبيق. في APK الشخصي، يرفع التطبيق الفيديو إلى Gateway الذي يحدده المستخدم عبر HTTPS أو LAN debug، ولا يرسل مفتاح Gemini أو أي اعتماد مزود إلى Gateway؛ يحتفظ الخادم بهذه الأسرار ويشغّل Python وFFmpeg وWhisperX خارج الهاتف.

## CI

يُشغّل workflow `Embedded Android App` اختبارات الوحدة وAndroid Lint وبناء Debug APK عند تغيير هذا المجلد.
