# معمارية مزامنة المستودعين

## النطاق

المستودع `ISM-dragon/-1` هو تطبيق سطح مكتب مبني على Tauri وReact، ويحتوي على Python Pipeline محلي وطبقة Gateway. أما المستودع `ISM-dragon/-` فهو تطبيق Android أصلي مبني على Kotlin وJetpack Compose وRoom وWorkManager وMedia3. لذلك لا تُعدّ ملفات `app/` في المستودعين بدائل مباشرة لبعضها.

## الطبقة المشتركة

تم اعتماد طبقة Gateway وPython Pipeline الموجودة في `ISM-dragon/-1` بوصفها طبقة المعالجة الخلفية المشتركة. نُقلت إلى المستودع Android حتى يستطيع التطبيق الأصلي استخدام المعالجة البعيدة نفسها عند تشغيل Gateway على جهاز يملك Python وFFmpeg واعتماديات Pipeline.

يظل عقد الاتصال الأساسي كما يلي:

| الوظيفة | المسار | ملاحظات |
|---|---|---|
| فحص الصحة | `GET /health` | لا يعيد أسرارًا |
| رفع مصدر خاص | `POST /v1/sources/uploads` ثم `PUT` chunks ثم `/complete` | Android يحسب SHA-256 ويستأنف من offset؛ `/v1/sources/upload` legacy للتوافق فقط |
| بدء المعالجة | `POST /v1/processing/jobs` | يدعم `llm` و`captions` و`mode` |
| متابعة المعالجة | `GET /v1/processing/jobs/{id}` | يعيد الحالة والتقدم والنتيجة |
| تنزيل الناتج | `GET /v1/processing/jobs/{id}/media/{filename}` | ملفات MP4 الموثقة فقط |
| فحص الإمكانات | `GET /v1/processing/capabilities` | يسبق إنشاء المهمة في العملاء الداعمين |
| التحليلات | `GET /v1/analytics/summary` | بيانات مصدرها موصل رسمي فقط |
| الجدولة الاجتماعية | `/v1/social/*` | وضع Mock للاختبار، والتكامل الحقيقي يحتاج OAuth رسميًا |

## ما بقي خاصًا بكل منصة

يحتفظ تطبيق Tauri بواجهة React، ومسار المعالجة المحلية، ومحرر المقاطع، ومكتبة المصادر، وواجهة Social Hub الخاصة به. ويحتفظ تطبيق Android بواجهة Kotlin وRoom وWorkManager وMedia3، واختيار ملفات `content://`، وإدارة المشاريع، والتحليل المحلي المتاح على الجهاز. لا ينبغي نسخ `app/src` أو `app/src-tauri` بين المستودعين لأن ذلك سيؤدي إلى خلط بيئتين مختلفتين.

## الأسرار والأمان

لا يرسل تطبيق Android مفتاح Gemini إلى Gateway. تُقرأ مفاتيح المزودين على الخادم من متغيرات البيئة أو ملفات أسرار غير متعقبة، ويجب استخدام `GATEWAY_TOKEN` طويلًا وHTTPS خارج الجهاز أو الشبكة المحلية. لا تُحفظ ملفات الوسائط أو قواعد SQLite أو المفاتيح السرية في Git.

## نسخة Android داخل المستودع الثاني

لأغراض المزامنة والتوزيع، توجد نسخة Android المطابقة لآخر `main` من المستودع `ISM-dragon/-` داخل المسار `android/`. هذا المسار مستقل عن `app/` الخاص بواجهة Tauri، ولا يغيّر مشروع سطح المكتب أو Gateway. يُشغّل الملف `.github/workflows/android-build.yml` اختبارات Android وLint وبناء APK عند تغيير ملفات `android/`.

## الاختبارات

يجب اختبار Gateway وPipeline ببيئة Python مستقلة، واختبار تطبيق Android عبر Gradle وLint واختبارات JVM. نجاح بناء Android لا يثبت توفر Python أو FFmpeg على Gateway، ونجاح Pipeline لا يثبت سلامة واجهة Android؛ كلا المسارين مطلوب للتحقق الكامل.

## قاعدة المزامنة المستقبلية

عند إضافة ميزة معالجة أو Gateway، تُنفذ أولًا في الطبقة المشتركة ثم يُحدّث عميل Tauri وعميل Android وفق العقد نفسه. أما ميزات الواجهة أو التخزين المحلي أو دورة حياة التطبيق، فتُنفذ داخل المستودع الخاص بالمنصة ولا تُنسخ آليًا إلى المستودع الآخر.
